# Интерфейс io.Reader и сканирование

LineCount принимает io.Reader, но из-за bufio.ScanWords считает слова. main читает строку и testdata/poem.txt, хотя подписи вывода называют результат количеством строк. Примеры Shape и LimitReader закомментированы.

Учебная папка `OOP/interfaces`. Код сохранён в исходном состоянии.

## Структура

- `.gitignore`
- `go.mod`
- `main.go`
- `testdata/poem.txt`

## Требования и команды

Проверено на Windows с Go 1.27.1 (windows/amd64); `go.mod` требует Go 1.27.1. Команды выполняются из корня репозитория. Для самостоятельной публикации добавлен go.mod; исходные .go не изменялись.

Точка входа: `main.go`.

```sh
go run .
```

```sh
go test ./...
go vet ./...
```
